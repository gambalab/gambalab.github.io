# Gambardella Lab website

Static site for the Gambardella Lab (TIGEM & Scuola Superiore Meridionale, Naples), served with GitHub Pages.

- `index.html` — home page (vision, research, papers, people, news, contact)
- `software.html` — software page (ESMRank, DREEP, GFICF, HONEY DeepVariant, sparseDist)
- `assets/` — emblem image and favicon

No build step: edit the HTML files and commit. To add a news item or paper, copy an existing row in `index.html` and change the text.
